02 / Your terminal stays yours

No loop.
No lock.

The old interactive loop is gone. A headless daemon waits in the background at zero idle CPU, executes the request, and gives your shell back in under 200 ms.

03 / One flat namespace

Native
routing.

A PowerShell function injected into your profile reads the live registry and immediately maps commands such as mae play or mae skip to the right sandboxed executable.

$PROFILE → registry.json

mae playmusic.exe / isolated

04 / Local, structured, reliable

TCP.
NDJSON.

Non-blocking localhost TCP sockets replace fragile named pipes. Newline-delimited JSON keeps every command structured, while a localized random token authenticates the conversation.

› 127.0.0.1:local

{"cmd":"play","q":"lofi"}
{"auth":"local-random-token"}
{"ok":true,"state":"queued"}

05 / No blocking prompts

Prompt.
Respond.
Dispatch.
Continue.

Search results return to an ephemeral CLI. You choose 1–5 there, then it sends a fresh stateless command to the daemon. Nothing waits. Nothing freezes.

01

Core Hub

Creates one registry and keeps each app in its own sandbox under LocalAppData.

02

Native router

Your PowerShell profile resolves the current registry before an executable is launched.

03

Local IPC

Authenticated TCP sockets exchange non-blocking NDJSON messages on localhost.

04

Stateless choices

The short-lived CLI handles a result selection and sends the next command fresh.

05

Self bootstrapping

The first install builds the platform; later installs register only their own commands.

06

Clean lifecycle

daemon.log records state. mae exit aggressively terminates mpv and prevents orphaned audio.
